Testing Module API (brand new)

The Testing module was previously entirely unexposed at the API layer — only DB tables + orphaned SPs existed. Now fully wired:

EndpointSP UsedPurpose
POST /api/testsfn_test_record_createCreate test record (status Pending)
GET /api/tests/pending— (direct query)List pending tests by center
GET /api/tests/{id}— (direct query)Get single record
GET /api/tests/{id}/resultsfn_test_result_get_by_recordGet all results for a record
POST /api/tests/{id}/resultsfn_test_result_addAdd individual TTHI marker result
POST /api/tests/{id}/completefn_test_record_update_statusMark record Completed
