  • Pagination: server-side via API, pagination bar with page numbers + prev/next
  • Donation history: wired to fn_donor_donation_get_by_donor SP (was orphaned, now connected)
  • Form: personal info (name, gender, DOB, blood group, occupation, language) + contact (phone, email, aadhaar, address fields)
  • Fallback: 15 mock donors when API is unavailable

Patterns & Conventions

  • Auth guard: every action checks _auth.IsAuthenticated, redirects to login if false
  • Mock fallback: try/catch around API calls, fall back to inline mock data for all list pages
  • TempData messages: TempData["Success"] banner after create/edit
  • ModelState validation: required field checks, error list displayed in red alert box
  • Consistent page header: .page-header with title/subtitle + action buttons
  • Stat cards: 4-up grid with colored icons, used on Donor Details + Camp Details
  • Table styling: sticky header, compact rows, hover highlight, badge for status/blood group
  • Dropdowns: blood group (8), gender (3), organizer (8), state (8), occupation (5), language (4)

How to run
1. Start API: dotnet run --project BloodCenterOS.API (port 5000)
2. Start Web: dotnet run --project BloodCenterOS.Web (port 5055)
3. Open http://localhost:5055 — login with admin / admin@123
4. Navigate to Donors, Camps, or Hospitals from the sidebar
