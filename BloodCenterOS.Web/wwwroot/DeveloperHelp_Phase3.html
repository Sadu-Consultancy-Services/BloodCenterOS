Cross Matching (Saline / Bovine / Coombs) + Blood Issuing with Payment

Overview

Phase 3 covers Cross Matching (3-test workflow: Saline, Bovine, Coombs) and Blood Issuing to patients (reservation-based with payment processing). Reference: BloodCenter24 forms CrossMatchEntry.cs + IssueToPatient.cs.

SPDescription

Data Flow

Reservation (Active) → Start Cross Match → 3 tests per component (Saline, Bovine, Coombs)
    → Auto pass/reject logic:
      • All Pass → OverallResult = 'Pass' → Ready for Issue
      • Any Reject → OverallResult = 'Reject' → Component released back

Ready for Issue → Select Payment Mode (Cash/Credit/None) → Issue
    → ComponentMaster.status = 'Issued'
    → ReservationDetail.Status = 'Issued'
    → PatientReservation.Status = 'Issued'
    → BillingTransaction + InvoiceDetail (if payment mode)
