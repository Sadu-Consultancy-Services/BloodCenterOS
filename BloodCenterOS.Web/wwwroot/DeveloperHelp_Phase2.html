Rate Management

Admin module for configuring blood component pricing:

  • UnitRate — Price per unit of blood component
  • ReservationRate — Service charge for reservation processing
  • Unique per (BloodGroup, ComponentType) combination
  • Soft delete (deactivate) instead of hard delete

Blood groups: A+, A-, B+, B-, AB+, AB-, O+, O- (8). Components: WB, PCV, FFP, PC (4).

Patient Reservation

Core workflow for allocating blood components to patients using FIFO (oldest expiry first):

  1. User enters patient details + blood requirement (blood group, component type, units)
  2. System queries fn_reservation_get_available_components — FIFO-orders by ExpiryDate
  3. Components are locked: ComponentMaster.currentstatus → 'Reserved'
  4. Reservation record + detail records created
  5. Optional: Invoice created in BillingTransaction + InvoiceDetail
  6. User can cancel → components released back to 'Available'
