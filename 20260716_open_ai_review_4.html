Architecture Decisions

DecisionChoiceRationale
Data AccessDapper + NpgsqlDirect SP invocation with dynamic mapping; no EF Core overhead
AuthJWT Bearer + BCryptStateless, self-contained tokens; BCrypt for password storage
Response PatternApiResponse<T>Consistent JSON envelope: {success, data, message, errors}
PaginationPagedResult<T>Standard: {items, totalCount, page, pageSize, totalPages}
Multi-tenantCenterId claimExtracted from JWT in each controller; passed to SPs
Error Handlingtry-catch per actionReturns 400/404/500 with ApiResponse.Fail
LoggingSerilog (Console + File)Structured JSON logs with rolling file sink
DI LifetimeScopedPer-request lifetime for repos and services
