JWT Auth Flow

Browser                          Web (MVC)                     API
  │                                │                            │
  ├─ POST /Account/Login ──────────┤                            │
  │   username/password             ├─ POST /api/auth/login ─────┤
  │                                │                            ├─ Verify BCrypt
  │                                │                            └─ Return JWT ──┐
  │                                ├─ Store JWT in TokenStore   ◄───────────────┘
  │                                ├─ Set bc_token cookie (HttpOnly)
  │  ◄─ 302 Redirect ─────────────┤
  ├─ GET /Home/Index ──────────────┤
  │   (sends bc_token cookie)       ├─ JwtCookieMiddleware reads cookie
  │                                ├─ Restores JWT into TokenStore
  │                                ├─ GET /api/inventory/stock ──┤
  │                                │   (Authorization: Bearer)   └─ Returns data
  │  ◄─ 200 Dashboard ────────────┤
  └─ Logout                        ├─ Clears TokenStore + cookies
                                   └─ Redirect to /Account/Login

Key Design Decisions

  • TokenStore singleton — in-process memory, survives redirects within same request. Cookie middleware rehydrates it on each new request.
  • ApiClient uses typed HttpClient — via AddHttpClient<ApiClient> for connection pooling, timeout, and base address from config.
  • Auth guard in every action — HomeController checks _auth.IsAuthenticated at the top of each action, redirects to login if missing. No [Authorize] filter yet (Phase 2).
  • Graceful degradation — if the API is unreachable, the dashboard falls back to mock data so the UI is always renderable.
  • No JS SPA pattern — server-rendered Razor Pages, full page loads. Keeps the architecture simple and aligns with the existing scaffold.

1. Start API: dotnet run --project BloodCenterOS.API (port 5000)
2. Start Web: dotnet run --project BloodCenterOS.Web (port 5055 from launchSettings)
3. Open http://localhost:5055 — login with admin / admin@123
4. Toggle theme via the sun/moon icon in the header
